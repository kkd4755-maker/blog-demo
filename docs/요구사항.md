# 요구사항

## 블로그 소개

- **주제**: 독서 기록
- **이름**: 책갈피 노트
- **한 줄 소개**: 읽은 책의 문장과 생각을 차곡차곡 모아두는 곳

## 화면

화면 전환은 라우터 없이 `useState` 로 처리한다.

1. **글 목록**: 작성된 글들을 모아 보여주는 첫 화면. 글을 누르면 글 상세로 이동한다.
2. **글 상세**: 선택한 글 하나의 전체 내용을 보여주는 화면.
3. **글쓰기**: 새 글을 작성하는 화면.

## 글 데이터 항목

| 항목 | 설명 |
| --- | --- |
| id | 글을 구분하는 고유 번호 |
| title | 글 제목 |
| content | 글 본문 |
| author | 작성자 |
| created_at | 작성 시각 |
