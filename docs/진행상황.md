## Supabase

- 프로젝트: `kkd4755-Vlog demo` (ID `rvauffmkklbotyapmtum`, 서울 지역). 학원에서는 "my-blog 프로젝트"라고 부름
- 테이블 `public.posts`
  | 열 | 타입 | 규칙 |
  | --- | --- | --- |
  | id | bigint | 자동 번호, 기본키 |
  | title | text | 비어 있으면 안 됨 |
  | content | text | 비어 있으면 안 됨 |
  | author | text | 비어 있으면 안 됨, 기본값 '익명' |
  | created_at | timestamptz | 비어 있으면 안 됨, 기본값 now() |
- RLS 켜짐. 정책 두 개
  - "누구나 글을 읽을 수 있음" (select, anon·authenticated)
  - "public can insert posts" (insert, anon) — 2일차 강사 SQL. 제목 1~100자, 내용 1~5000자, 작성자 1~30자
- 권한: anon 은 select·insert, authenticated 는 select. update·delete 권한은 아무에게도 없음
- **글 비밀번호** (2일차, 글마다 비밀번호를 정하고 그 비밀번호로만 지움)
  - 비밀번호는 `private.post_passwords`(post_id, password_hash) 에 bcrypt 로 바꿔서 보관. private 스키마는 API 로 보이지 않음. 글이 지워지면 함께 지워짐
  - `public.create_post(p_title, p_content, p_author, p_password)` → 새 글 id. 비밀번호 4~72자. 글쓰기 화면은 이 함수를 씀
  - `public.delete_post(p_id, p_password)` → 비밀번호가 맞으면 지우고 true, 아니면 false
  - 두 함수 모두 security definer, anon·authenticated 만 실행 가능
  - 이 기능 전에 만든 글(비밀번호 없음)은 화면에서 지울 수 없음 → 대시보드에서 지울 것
- 들어 있는 글 4개: "첫 번째 글", "두 번째 글" (작성자 "운영자"), "연습 3번째 글"(STEP 13 확인용으로 대시보드에서 직접 넣음), "안녕하세요"(2일차에 강사가 배포된 블로그에서 비밀번호를 정해 씀). 앞의 두 글의 created_at 이 같으므로 정렬할 때 id 도 함께 기준으로 쓸 것
- 테이블과 글은 Supabase 서버에 있으므로 어느 컴퓨터에서든 그대로 있음

## 디자인 규칙

새 화면도 지금 디자인과 같은 규칙을 따른다.

- **분위기**: 바랜 종이 위에 먹 갈색 글씨, 종이책처럼 차분한 느낌
- **글꼴**: Noto Serif KR 하나만 (Google Fonts, `App.css` 맨 위에서 불러옴). 바탕체 같은 옛날 명조체는 "너무 올드하다"고 해서 바꿈
- **색** (`App.css` 의 `:root` 변수)
  | 변수 | 값 | 쓰임 |
  | --- | --- | --- |
  | `--paper` | `#eee3cc` | 배경 |
  | `--ink` | `#3a2718` | 제목, 본문 |
  | `--pencil` | `#75604e` | 날짜, 작성자 같은 보조 글씨 |
  | `--ribbon` | `#2f5141` | 가름끈, 포커스, 마우스 올림 |
  | `--ochre` | `#c9a86a` | 연필 밑줄 |
- **눈에 띄는 장치는 두 개만**: 블로그 이름 옆 초록 가름끈(글 상세에서 길게 내려옴), 인용문 아래 연필 물결 밑줄(`.underline`)
- **레이아웃**: 왼쪽 여백 칸(`--margin`)에 날짜·가름끈, 오른쪽에 내용. 모두 왼쪽 정렬. 모바일(600px 이하)에서는 날짜가 제목 위 한 줄로
- **글자 크기**: 본문 18px, 작은 글씨도 16px 이상
- **쓰지 않기로 한 것**: 둥근 카드 목록, 가운뎃점으로 이은 정보(`A · B`), `제목 — 부제` 형태, 버튼 글자 뒤 화살표(→). 대신 "책갈피 씀", 『책 제목』, 부제 처럼 쓴다
- **움직임**: 가름끈이 내려오는 것 하나뿐. 움직임 줄이기 설정을 켠 기기에서는 움직이지 않게

## 작업 시작·끝

- 시작할 때: `git pull` (처음 받는 컴퓨터면 `git clone https://github.com/kkd4755-maker/blog-demo.git` → `npm install`)
- 새 컴퓨터(집, 초기화된 학원 컴퓨터)에서 한 번만 할 것
  1. Supabase 플러그인 설치 — 터미널에서
     ```
     claude plugin marketplace add anthropics/claude-plugins-official
     claude plugin install supabase@claude-plugins-official
     ```
     그다음 Claude Code 에서 `/reload-plugins` → `/mcp` 로 Supabase 로그인
  2. 프로젝트 루트에 `.env.local` 만들고 값 채우기 — Supabase 대시보드 → Project Settings → API 에서 복사하거나, Claude 에게 "Supabase 프로젝트 URL 과 publishable 키로 .env.local 채워줘". `=` 바로 뒤에 붙여 넣을 것 (따로 줄을 만들면 빈 값이 됨)
     ```
     VITE_SUPABASE_URL=
     VITE_SUPABASE_PUBLISHABLE_KEY=
     ```
- 실행: `blog0demo`(집에서는 `blog-demo`) 폴더 안에서 `npm run dev` → http://localhost:5173/blog-demo/ (base 때문에 뒤에 `/blog-demo/` 를 붙임. 바깥 폴더에서 실행하면 실패함)
- 끝날 때: 이 문서의 체크리스트를 고치고 `git add -A` → `git commit -m "..."` → `git push`
